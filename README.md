# ML_Book

# Machine Learning Algorithms, From Scratch

## Overview

This repository is a personal collection of **Machine Learning algorithms implemented from scratch**.  
The main idea behind this work is to understand **how learning actually happens inside a model**, instead of depending on high-level libraries.

Each algorithm is written with clear logic, simple structure, and readable code, focusing more on **conceptual clarity** than performance.

At present, this project includes implementations of **Linear Regression**, **Logistic Regression** and **DecisionTree**.

---

## Purpose of This Book

This repository is maintained like an **ML learning book**, where:
- Every algorithm is written step by step
- The math is converted directly into code
- No black-box functions are used

The goal is to build strong foundations before moving to advanced frameworks.

---

## Implemented Chapters

### Chapter 1: Linear Regression

- Linear equation: `y = wx + b`
- Mean Squared Error as loss function
- Gradient Descent for optimization
- Manual weight and bias updates

Implemented using basic Python logic to clearly show how learning happens.

---

### Chapter 2: Logistic Regression

- Sigmoid function for probability output
- Binary Cross-Entropy loss
- Gradient Descent optimization
- Binary classification (0/1)

Implemented using NumPy only for numerical operations.

---

### Chapter 3: Decision Tree

-Feature-based splitting
-Gini Impurity / Entropy
-Information Gain
-Tree-based classification

## Code Philosophy

- No use of `scikit-learn`, `TensorFlow`, or `PyTorch`
- Logic is written manually
- Code is readable and beginner-friendly
- Focus is on understanding, not speed
